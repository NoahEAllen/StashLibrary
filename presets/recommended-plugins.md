# 推荐 Plugins 勾选表

在 Web UI → Settings → **Plugins** → Community (stable) 中搜索安装。  
（不是 Metadata Providers 页。）

| 优先级 | UI 搜索词（约） | 作用 | 必装？ |
|--------|-----------------|------|--------|
| 1 | `File Monitor` | 监视目录变化，辅助发现新文件 | 建议 |
| 1 | `Stash Notifications` | 刮削器/插件更新提醒 | 建议 |
| 1 | `Scene Marker Tags to Scene` | Marker 标签同步到场景 | 建议 |
| 2 | `VideoScrollWheel` | 滚轮调进度/音量 | 可选 |
| 2 | `Video Chapter Markers` | 片内章节 → Markers | 可选 |
| 2 | `Stats` | 仪表盘统计 | 可选 |
| 2 | `Scene Cover Cropper` | 裁封面 | 可选 |
| 3 | `AI Tagger` | 模型自动打标签（较重） | 可选，后装 |
| 3 | `renamer` / `renamerOnUpdate` | 按元数据重命名文件（有风险） | 可选，慎用 |

说明与注意事项见 [docs/plugins.md](../docs/plugins.md)。
